# Ian's Custom Room Card

A customizable room card for Home Assistant dashboards.

**Features:**
- Room icon with optional entity-driven badge
- Configurable background color, opacity, and image
- Sub-buttons with individual tap/hold/double-tap actions
- Global tap action that turns the entire card into a navigation target
- Jinja2 template support for icon, color, badge, and title
- Full visual editor — no YAML required for basic use
- card-mod compatible (CSS custom properties + `::part()` selectors)

See [README](https://github.com/linkian19/ha-ians-custom-room-card) for full documentation.
